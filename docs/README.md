# 文档入口

当前项目文档以根目录 [`README.md`](../README.md) 为准，内容包括：

- 安装与配置
- provider 管理和 CLI 启动
- 稳定 Home、权限和安全边界
- 开发、测试和检查流程

`docs/archive/` 保存历史需求、方案、验证记录和数据库研究。归档内容只用于追溯，不是当前规范；不要引用、修改或根据其中的旧命令和旧模块名推断当前实现。

如果实现行为发生变化：

1. 先更新测试和代码。
2. 在根目录 README 中更新必要的用户可见说明。
3. 只有确实需要保留决策背景时，才新增单独的当前文档；不要恢复按日期堆积的过程文档。
